# Detecção de Objetos com YOLO e OpenCV

Projeto em Python que utiliza YOLO e OpenCV para realizar detecção de objetos em tempo real através da câmera do computador.

Tecnologias utilizadas

* Python
* OpenCV
* Ultralytics YOLO

1. Abre a câmera do computador.
2. Captura os frames em tempo real.
3. Envia cada frame para o modelo YOLO.
4. Identifica objetos presentes na imagem.
5. Desenha as detecções na tela.
6. Permite encerrar o programa pressionando "S".



Objetivo

Este projeto foi desenvolvido como estudo de visão computacional, explorando o uso de modelos de inteligência artificial para detecção de objetos através de uma câmera em tempo real.
